This module adds IDS (Industriestandard Datenaustausch) protocol support for Punchout.

IDS is a German industry standard for electronic data exchange between
suppliers and buyers, commonly used in the German technical wholesale trade.

Features:

- IDS 1.3 and 2.5 version support
- Customer authentication (name_kunde, kndnr, pw_kunde)
- XML-based shopping cart parsing
